
# 🛡️ SPH MENU — Профессиональный игровой комплекс для Dota 2

Многофункциональный программный комплекс **SPH MENU** создан для автоматизации игровых механик, микроконтроля, отслеживания таймингов и глубокой кастомизации игрового клиента Dota 2. Приложение работает в тесной интеграции с игровой телеметрией и Windows API, обеспечивая максимальную отзывчивость и стабильность.

## ⚡ 1. Модуль уклонения (Dodger)

Инструмент для автоматического выполнения сложных микро-моментов и избежания вражеских заклинаний/атак.

* **Автоматический кастинг предметов:** По нажатию клавиши доджа скрипт мгновенно сканирует область вокруг вашего героя и последовательно прожимает назначенный предмет (например, *Eul's Scepter*, *BKB*, *Manta Style* или стики) по спирали.
* **Интеллектуальный фокус героя:** Перед выполнением серии кликов автоматически производит двойной тап по клавише выбора вашего героя, предотвращая случайные мисклики по карте.
* **Гибкая настройка радиуса и шага:** Полная кастомизация рабочей зоны поиска целей и задержек между действиями через удобное диалоговое меню.

## 🌾 2. Автоматизация фарма (Farm Engine)

Максимизация эффективности фарма и управления юнитами (иллюзиями/клонами).

* **Точечный маршрут:** Возможность расставлять кастомные точки фарма прямо на карте с помощью горячей клавиши (`F11`).
* **Распределение иллюзий (`F6`):** Интеллектуальный распределитель юнитов, который поочередно переключает группы и отправляет иллюзии на указанные лагеря нейтральных крипов.
* **Умный Last-Hit через Shift (`F7`):** Автоматизация зачистки стаков с удержанием очереди команд (`Shift-queue`), что позволяет безошибко фармить несколько лагерей подряд.

## 🎯 3. Комбо-трекер и визуализатор (Combo Tracker)

Ассистент для наведения и реализации комбинаций способностей по полоскам здоровья врагов.

* **Сканирование шкалы HP:** Автоматический поиск и захват полоски здоровья вражеского героя в радиусе видимости курсора на базе анализа пикселей.
* **Динамический оверлей (Анти-скриншот):** Отрисовка на прозрачном поверхностном слое направляющих стрелок и маркеров атаки точно на позиции врага.
* **Интеграция со скриптами:** Поддержка выбора внешних конфигурационных файлов (`.txt`) для построения последовательностей действий.

## 📊 4. Игровая телеметрия и таймеры (GSI & HUD Overlays)

Встроенный локальный HTTP-сервер для обработки Game State Integration (GSI) в реальном времени.

* **Таймеры ключевых объектов:** Отображение точного времени до появления рун богатства (**Bounty**), рун опыта (**Wisdom**) и лотосов (**Lotus Pools**) прямо на экране.


* **Монитор консоли (Aegis Tracker):** Фоновый анализатор файла `console.log` игры, который моментально фиксирует подбор Эгиды бессмертия (**Aegis of the Immortal**) и выводит визуальный таймер обратного отсчета на 5 минут с зеленым индикатором.



## 📷 5. Модификация клиента и Камера (Camera Hack)

Инструменты для изменения стандартных ограничений интерфейса и графики.

* **Отдаление камеры:** Интеграция с утилитой `maphack.exe` для регулировки дальности обзора (Zoom Hack) с возможностью быстрого включения/отключения.


* **Системные утилиты (Dota Utils):**
* Автоматический поиск и привязка к папке игры `Dota 2`.


* Быстрая установка пользовательских модов из локальной директории `./mod`.


* Автоматическая генерация оптимизированного файла `autoexec.cfg`.


* Установка готового конфигурационного профиля GSI для связи с сервером.





## 🛡️ 6. Безопасность и интерфейс (Smart Overlay System)

* **Контекстное меню:** Компактная плавающая панель (`◍ SPHERA`) с поддержкой перетаскивания мышей, которая автоматически скрывается при переключении в браузер или другие программы, оставаясь видимой только поверх игрового клиента Dota 2.


* **Прозрачный UI:** Использование продвинутых WinAPI-флагов (`WS_EX_TRANSPARENT`), благодаря которым оверлей абсолютно не мешает игровому процессу и невидим для стандартных средств захвата экрана.
